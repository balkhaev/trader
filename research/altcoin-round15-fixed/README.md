# Altcoin fixed-rule screen — Round 15

Изолированный исследовательский прогон по широкому Binance USD-M universe без изменений торгового runtime.

## Граница

- 36 заранее зафиксированных альткоин perpetual-контрактов; BTC/ETH не входят в рейтинг.
- Официальные monthly 15m klines и fundingRate за 2025-07 — 2026-06.
- Каждый ZIP принимается только после сверки соседнего SHA-256 `.CHECKSUM`.
- Семь заранее заданных механизмов: flow trend, flow exhaustion, squeeze breakout, sweep/reclaim, trend pullback, cross-sectional residual momentum и cross-sectional flow exhaustion.
- Никакой индивидуальной оптимизации по монете.
- Route `coin × setup` фиксируется только по 2025 H2. После этого параметры и состав не меняются, а 2026 H1 считается фактическим периодом.
- Сигнал формируется после закрытия 15m-бара; вход не раньше следующего open.
- Одна позиция на контракт, без пирамидинга и overnight.
- Сделки, пересекающие фактическое funding-событие, не открываются.
- Базовые издержки 12 bps за полный оборот, стресс 20 bps.

## Артефакт

Workflow сохраняет полный рейтинг всех `coin × setup`, выбранные до 2026 маршруты, все сделки 2026 H1, помесячную стабильность, bootstrap и портфель $10 000 с ограничением числа одновременных позиций.

Payload хранится как gzip/base64 chunks только из-за лимита GitHub connector. Workflow объединяет его, проверяет SHA-256, компилирует Python и прикладывает декодированный исходный код к результатам.

Исследование не содержит API-ключей, не вызывает торговые endpoints и не меняет продуктовый код.
