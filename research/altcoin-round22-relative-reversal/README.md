# Round 22 — cross-sectional residual reversal

Новая общая стратегия для 80 альткоинов, без coin-specific параметров.

После 45-минутного падения измеряется отклонение монеты от медианного движения всего universe. Вход допускается только при объёмном reclaim-баре с длинной нижней тенью. На одном entry-bar требуется не менее трёх кандидатов; берутся три сильнейших.

До июля фиксированы шесть экономически понятных вариантов:

- idiosyncratic падение против спокойного рынка;
- broad-market capitulation;
- без market-regime фильтра;
- loose 45m и strict 60m версии.

Конфигурация выбирается только по отдельным результатам 2025 H2 и 2026 H1. Затем неизменённо проверяется июль 2026.

Исполнение: next 15m open, stop 1.5 ATR, target 2R, one position per symbol, top-3 per event, max 10 positions, no overnight, skip funding-crossing, 12/20 bps.
