# Altcoin universe research — Round 14

Изолированный исследовательский прогон для широкого Binance USD-M universe.

## Граница исследования

- 36 заранее зафиксированных альткоин-контрактов; BTCUSDT и ETHUSDT используются только как benchmark/context.
- Официальные monthly 5m archives с `data.binance.vision` за 2024-01 — 2026-06.
- Каждый принятый ZIP проверяется по соседнему SHA-256 `.CHECKSUM`.
- Пять общих семейств: taker-flow impulse, flow exhaustion, squeeze breakout, range sweep/reclaim, trend pullback.
- Параметры фиксируются на календаре 2024; coin-route выбирается по данным не позднее 2025-12-31; результат 2026 H1 считается без изменения состава.
- Сигнал только после закрытия бара, вход не раньше следующего 5m-бара, одна позиция на контракт, overnight запрещён.
- Базовые издержки 12 bps, стресс 20 bps; funding добавляется финальным кандидатам.

## Почему payload разбит на части

GitHub connector передаёт исследовательский runner как gzip/base64 chunks. Workflow объединяет их, проверяет SHA-256, компилирует Python и кладёт декодированный исходник в итоговый artifact вместе со всеми таблицами и отчётом.

Ветка и PR не изменяют продуктовый код и не содержат API-ключей или торговых действий.
