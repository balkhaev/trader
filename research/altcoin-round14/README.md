# Altcoin universe research — Round 14

Изолированный исследовательский прогон для широкого Binance USD-M universe.

## Граница исследования

- 36 заранее зафиксированных альткоин-контрактов; BTCUSDT и ETHUSDT исключены из рейтинга кандидатов.
- Официальные monthly 5m klines и fundingRate archives с `data.binance.vision` за 2024-01 — 2026-06.
- Каждый принятый ZIP проверяется по соседнему SHA-256 `.CHECKSUM`.
- Пять общих семейств: taker-flow impulse, flow exhaustion, squeeze breakout, range sweep/reclaim, trend pullback.
- Параметры фиксируются на календаре 2024; coin-route выбирается по данным не позднее 2025-12-31; результат 2026 H1 считается без изменения состава.
- Сигнал только после закрытия бара, вход не раньше следующего 5m-бара, одна позиция на контракт, overnight запрещён.
- Сделки, пересекающие фактическое funding-событие конкретного контракта, не открываются.
- Базовые издержки 12 bps, стресс 20 bps.

Все Python-модули хранятся в читаемом виде в `src/`, компилируются перед запуском и копируются в итоговый Actions artifact вместе с полным grid, отрицательными результатами, рейтингом монет и портфельным расчётом.

Ветка и PR не изменяют продуктовый код, не содержат API-ключей и не вызывают торговые endpoints.
