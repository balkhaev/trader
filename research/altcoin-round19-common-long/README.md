# Round 19 — common LONG60

Проверяется один общий маршрут на широком альткоин-universe, без индивидуальных параметров по монете.

## Почему выбран LONG60

До чтения июля 2026 общая long-reversal версия имела:

- 2025 H2: 797 сделок, +21,28 bps после 12 bps, PF 1,48;
- 2026 H1: 844 сделки, +34,35 bps, PF 2,04.

Это максимальный минимум ожидания между двумя периодами среди общих long-вариантов.

## Clean cohort

Из чистой когорты исключены все монеты, чьи июльские результаты уже были раскрыты или заранее назначены другому июльскому прогону. Остальные контракты получают один и тот же LONG60 без coin selection.

Исполнение: 15m сигнал, next-bar open, стоп 1,5 ATR, цель 2R, максимум 60 минут, no overnight, skip funding-crossing, 12/20 bps.
