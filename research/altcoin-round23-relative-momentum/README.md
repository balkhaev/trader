# Round 23 — cross-sectional relative momentum

Новая общая momentum-стратегия для 80 альткоинов без индивидуальных параметров.

После сильного 45-минутного роста монета должна одновременно:

- заметно опережать медианное движение universe;
- закрыться в верхней части свечи;
- иметь положительный taker imbalance;
- показать повышенный объём;
- не иметь слишком большой верхней тени.

На одном entry-bar требуется минимум три кандидата; берутся три сильнейших. Проверяются шесть заранее ограниченных вариантов: спокойный рынок, broad-up regime и отсутствие regime-фильтра, в loose 45m и strict 60m исполнении.

Выбор конфигурации выполняется только по отдельным результатам 2025 H2 и 2026 H1. Затем правило неизменно проверяется на июле 2026.

Исполнение: next 15m open, stop 1.5 ATR, target 2R, top-3, max 10 positions, one position per symbol, no overnight, skip funding-crossing, 12/20 bps.
